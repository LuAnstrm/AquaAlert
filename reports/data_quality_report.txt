7. NOTES FOR THE TEAM
──────────────────────────────────────────────────────────────────────
  All numeric thresholds used in feature engineering are PROTOTYPE
  ASSUMPTIONS. Validate them against local NCR historical data
  before using this dataset in a production system.
  flood_risk is derived from the source binary FloodOccurrence: High
  = recorded flood; Moderate = no flood but daily rain >= 20 mm or
  river level >= 2.5 m; Low = otherwise. In the source data
  FloodOccurrence equals (rainfall >= 30 mm) on every row, so the
  target is a deterministic function of rainfall and water level.
  The wettest day in the data is 52.7 mm. Documented major Metro
  Manila floods (JICA 2014, Table 2.6) had 149-291 mm of basin
  rainfall in one day, so typhoon-scale events are absent from
  training.
